# Third-party references and optional tools

The MIT License covers the original SlotVFX skill text, workflow guidance and included helper scripts. It does not relicense third-party pages, images, GIFs, game assets, software or trademarks linked from the skills. Those works remain with their respective owners.

- The slash reference study links to Roman Rait's public Hero Wars gallery and GIFs, Cyanilux's shader breakdown, and discussions by their authors on Real Time VFX. No reference image or GIF is included here. The study retains its source links and distinguishes observations from interpretation.
- The Fairy Spins worked example is a fictional workflow description. Its original project files, art, generated keys and footage are not included.
- The motion-craft skill was informed by studying public agent-skill collections: HeyGen's HyperFrames (Apache-2.0), GreenSock's GSAP skills, Remotion's agent skills, the animation-principles collection by dylantarre, LottieFiles' motion-design-skill (MIT) and the disney-animation-rule-skill from vibe-motion. No text or code was copied from them; its numbers were measured in SlotVFX or are cited as starting points. The ease bezier constants are the widely published easings.net approximations. Its `motion_keys.py` helper is original and uses only the Python standard library. The Spine character guidance draws on published animation teaching (Thomas and Johnston, Williams, Lasseter 1987, Jonathan Cooper's Game Anim, Animation Mentor and AnimSchool tutorials) and on amounts measured from Esoteric Software's Spine Boy example in spine-runtimes; no text, code or example data was copied from them.
- The optional `package_previews.py` helper calls separately installed `ffmpeg` and `ffprobe`; the optional `analyze_gif.py` helper uses separately installed Pillow. Those tools and their licenses are not bundled.

If a contribution adds an external reference, cite its creator and source. Do not copy production assets or substantial third-party material into this repository without permission and an appropriate notice.
