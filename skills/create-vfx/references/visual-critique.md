# Visual critique and coordinated effects

Use this for a new visual direction or an effect that technically works but reads poorly. Keep the project's art style, scale and requested scope. Apply pixel-specific palette steps or low-frame-rate posing only when the brief calls for them.

## Establish the intended read

Describe the effect in a sentence: purpose, dominant shape/material, motion, palette and main timing cue. Inspect suitable existing project effects and assets first. Preserve approved art and animation; use the smallest change that addresses the request.

When direction is open and comparison would help, explore a few distinct silhouettes or timing ideas in named groups/clips. Compare at the same display size and background. A recolor is a color variant, not a different motion design. A narrow revision or approved direction usually needs one focused edit, without additional drafts. Retain alternatives unless their deletion is authorized.

## Diagnose before adding detail

Watch natural playback at gameplay size over the real art. Identify the dominant visible problem, change the relevant cause, then compare again. A bounded frame capture can help diagnose shape or a contact frame; motion still needs playback. Keep captures and exported files within the requested output scope.

| Observed problem | Useful next adjustment |
|---|---|
| Muddy silhouette or weak focal point | Simplify competing shapes; separate foreground values; reduce internal noise while retaining the requested material. |
| Floaty impact | Inspect the approach/contact timing. Sharpen the attack or accent the contact, then preserve enough recovery to communicate weight. |
| Washed-out color | Inspect glow/bloom and additive overlap. Restore the material's color/value structure; judge brightness over the real background. |
| Unintentionally mechanical motion | Vary secondary sizes, delays or trajectories where appropriate. Keep deliberate machine rhythm, alignment and synchronized beats. |
| Flat depth | Use supported layer order, occlusion or Spine interleaving to distinguish near/far material around the subject. Check silhouettes during movement. |
| Abrupt disappearance or loop jump | Check the intended end/stop contract, tails and last-to-first motion. Repair the discontinuity without shortening a deliberate hold. |
| Smoke reads as a sticker | Make it translucent with a lit top; let it swell, thin and drift instead of holding one size and alpha. |
| Strong effect on a target that does not react | If target animation is within scope, coordinate a suitable reaction (flash, push and spring back, tint) on the contact beat; see [Impact punctuation](../../slot-vfx-motion-craft/SKILL.md#6-beats-rhythm-and-win-escalation). For an FX-only revision, align to the existing performance and describe any proposed host reaction. |
| Effect and actor disagree | Align attachment position, release/contact cue and reaction using the actual animation, then inspect them together. |

These are diagnoses, not a style preset. A restrained painted effect, a precise mechanical effect and a luminous spell need different solutions. Preserve intentional hard cuts, long holds and static final poses.

## Coordinate the event

For an actor or symbol interaction, identify the existing preparation, release/contact and recovery cues. Match the FX origin to the relevant hand, muzzle, cell or target anchor. Coordinate the impact, requested symbol/Spine response and sound against the same cue. Inspect the target reaction as well as the emitter.

Use real clip times and frame rates. Speed keys, trims and bar speed change played timing; read back resolved durations/endpoints before aligning events. Timeline Director is useful for fixed arrangements. Marker ties, title cards, music and Blends require Editor only sequences. Game integration uses supported runtime events/host coordination; do not assume those recording extras export as gameplay controls.

Edit character/symbol animation only within the request. For an FX-only revision, align to the existing performance and identify any additional host work. Hit-stop, when requested, needs an explicit owner and affected clocks. Apply it only to the authorized host clocks, including a broader world pause when the user requests one; preserve clocks excluded by the brief. Do not assume an MCP global-pause feature or substitute editor playback controls for host integration. Existing Spine approvals and protected-pose rules still apply.

## Compare fairly and finish

Keep assets, framing, display size, background, FPS and playback conditions consistent. Keep the seed fixed where the tool exposes one; otherwise assess repeatability without inventing seed parameters or claiming pixel-identical output. Check other supported seeds or realistic copy counts when randomness or repetition affects the result.

Observe the first response, main beat, recovery and any loop seam. Check bounds and cleanup after the agreed stop/tail, respecting deliberate sustained content. Tool diagnostics establish configuration or mechanical behavior; a visual verdict needs observed frames/playback. When the app is unavailable, provide a plan or diagnosis and clearly leave visual/runtime checks unverified.

Repeat according to the remaining visible problem rather than a fixed number of rounds. Finish when the requested read, timing and integration conditions hold. Leave the intended clip selected/framed in SlotVFX and describe the relevant change. Saving, recording, exporting, publishing and cleanup retain their existing authorization boundaries.
